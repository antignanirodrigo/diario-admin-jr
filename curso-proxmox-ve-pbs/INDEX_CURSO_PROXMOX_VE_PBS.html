📊 Referência Rápida — Curva ABC de Comandos Proxmox VE & PBS

Classificação dos comandos ensinados no curso pela frequência e impacto real no dia a dia da infraestrutura:

A Essencial (80% do dia a dia): Comandos de operação contínua, status, ciclo de vida e backup.
B Regular (15% da operação): Configuração de hardware, storage, SDN e manutenção programada.
C Especializado (5% de crise/projeto): Disaster recovery, substituição de vdevs, quorum desempate e fencing.

🖥️ Gestão de VMs KVM (qm)

  • Aqm list / statusLista e audita o estado das VMs
  • Aqm start / stopInicia ou desliga uma VM
  • Aqm guest cmd <vmid> pingComunicação direta via Guest Agent
  • Bqm create <vmid> --memoryProvisionamento via linha de comando
  • Bqm set <vmid> --scsihwAltera controladores VirtIO a quente
  • Bqm snapshot / rollbackCriação e reversão rápida de estado
  • Cqm migrate <vmid> <target> --onlineLive-migration entre nós do cluster
  • Cqm disk move <vmid>Migra discos virtuais entre storages

📦 Containers LXC (pct)

  • Apct list / statusInventário de containers ativos
  • Apct enter <vmid>Abre shell root dentro do container
  • Apct start / stopCiclo de vida do container
  • Bpct create <vmid> <tmpl>Cria container a partir de template
  • Bpct set <vmid> -mp0Configura Bind Mounts de storage
  • Bpct clone <vmid> <newid>Clonagem linked instantânea
  • Cpct exec <vmid> -- <cmd>Executa comando sem login interativo

💾 Storage & ZFS (pvesm / zpool)

  • Apvesm statusStatus e ocupação de todos os storages
  • Azpool statusSaúde e integridade dos pools ZFS
  • Bzpool scrub <pool>Varredura e autocura de checksums
  • Bpvesm alloc / freeAlocação direta de volumes
  • Blvs -a / vgsAuditoria de pools LVM-Thin
  • Czpool replace <pool> <old> <new>Substituição e resilver de disco defeituoso
  • Cpvesm add nfs <id> --serverMapeamento de storage compartilhado

🛡️ Proxmox Backup Server (PBS)

  • Aproxmox-backup-client backupDispara backup deduplicado em chunks
  • Aproxmox-backup-manager datastore listOcupação e deduplicação global
  • Bproxmox-backup-manager garbage-collectionExecuta GC Mark & Sweep
  • Bproxmox-backup-manager verify-jobValidação SHA-256 de integridade
  • Bproxmox-file-restore list / extractRestauração granular de arquivos via FUSE
  • Cproxmox-backup-client key paperkeyGera chave física para cofre de segurança
  • Cqmrestore <bkp> <vmid> --live-restore 1Live-restore com streaming sob demanda

🌐 Redes, SDN & Firewall

  • Aifreload -aAplica mudanças de rede a quente
  • Abridge vlan showAudita tabelas de VLANs 802.1Q
  • Bpvesdn reloadCompila e aplica zonas e VNETs SDN
  • Bpve-firewall status / compileAuditoria das regras de firewall
  • Ctcpdump -i tap<vmid>i0 -nRastreamento de pacotes na interface da VM
  • Cbridge fdb showTabela de encaminhamento MAC na bridge

🏛️ Cluster, Quorum, HA & Ceph

  • Apvecm statusStatus do cluster e estado Quorate
  • Aha-manager statusEstado dos serviços sob Alta Disponibilidade
  • Bcorosync-cfgtool -sSaúde dos anéis de rede do Corosync
  • Bpveceph statusSaúde do cluster hiperconvergente Ceph
  • Bha-manager set <vmid> --state startedProtege recurso no HA CRM
  • Cpvecm qdevice setup <ip>Configura 3º voto desempate de Quorum
  • Cpvecm expected <votos>Força quorum temporário em crise
