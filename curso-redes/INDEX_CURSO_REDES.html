📊 Referência Rápida — Curva ABC de Comandos de Redes

Classificação dos comandos ensinados no curso pela frequência e impacto real no diagnóstico de rede do dia a dia:

A Essencial (80% do dia a dia): Diagnóstico de camada, conectividade e acesso remoto.
B Regular (15% da operação): Configuração de firewall, NAT, VPN e compartilhamento.
C Especializado (5% de crise): Captura de pacotes, VLAN vazando, diagnóstico combinado.

🌐 Diagnóstico de Camada

  • Aping -c 4 <host>Confirma que o host responde no nível IP
  • Aip a / ip routeEndereço, máscara e rota configurados na interface
  • Ass -tlnpQuem está escutando em qual porta
  • Bmtr <host>Traceroute + perda + latência por salto, ao vivo
  • Bnc -zv <host> <porta>Testa se o caminho até a porta realmente responde

🧭 DNS e DHCP

  • Adig / nslookup <host>Consulta DNS direta, sem cache local
  • Bresolvectl statusServidor DNS e cache em uso agora
  • Bcat /etc/hostsAtalho local que pode mascarar o DNS real
  • Bjournalctl -u dhcpcd -fAcompanha a negociação D.O.R.A. ao vivo

🔥 Firewall (nftables)

  • Anft list rulesetLê as regras ativas antes de mudar qualquer coisa
  • Bnft -f backup.nftRestaura backup — a rede de segurança do rollback
  • Bnft add rule ... ct state established,related acceptSempre libera a própria sessão antes de restringir o resto

🔑 SSH e Acesso Remoto

  • Assh-keygen -t ed25519Gera par de chaves — a privada nunca sai da máquina
  • Bssh -J <jump> <destino>ProxyJump, salta por um host intermediário
  • BPermitRootLogin noDiretiva de hardening no sshd_config

🔀 NAT

  • Bnft ... masqueradeSNAT dinâmico — uma regra pra toda a rede de saída
  • Bnft ... dnat to <ip>:<porta>Port forwarding — tradução, não permissão

🔒 VPN WireGuard

  • Bwg genkey / pubkeyGera o par de chaves do peer
  • Awg-quick up / downSobe e derruba o túnel
  • Bwg showHandshake e tráfego real — confirma se está passando dado

📡 Captura de Pacotes

  • Ctcpdump -i <iface> -nCaptura ao vivo, sem resolver nomes
  • Ctcpdump host X and port YFiltra só o que interessa
  • Ctcpdump -w arquivo.pcapSalva a captura como evidência real

🏷️ VLAN

  • Cip link add link eth0 name eth0.10 type vlan id 10Cria subinterface marcada com a tag 802.1Q
  • Cbridge vlan showAudita quais VLANs cada porta do switch aceita

📂 NFS e Samba

  • Bexportfs -ra / showmount -eAplica e audita os exports do NFS
  • Bmount -t nfs <host>:/caminho /mntMonta o compartilhamento remoto
  • Bsmbpasswd -a <user> / testparmCredencial Samba e validação do smb.conf
